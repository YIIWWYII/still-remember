# 寄往将来 · 设计说明

「仍然记得」的时间档案新章节。以“尚未抵达的年份”为入口：选一个启封年份，写下一封会被封存的信，看到它变成一张带蜡封的信纸，最后进入“已经寄出的信”。

## 文件

- `letter.html` — 单屏网页（设计工作台可直接打开）
- `tokens.css` — 颜色、字体、间距与圆角变量
- `app.css` — 全部版式与响应式规则
- `letter.js` — 年份刻度、实时预览、封存、草稿与隐私弹窗
- `design.json` — 工作台工程元数据
- `assets/` — 本地摄影与思源宋体子集
- `_card_title.html` / `_card_end.html` — 录制视频的首尾卡（下划线开头，不上画布）

## 打开

在本目录起一个静态服务器，例如：

```sh
python -m http.server 8791
```

访问 `http://127.0.0.1:8791/letter.html`。嵌入 React 时加 `?embed=1`，会隐藏本页头部与页脚，交给外层应用的外壳。

## 设计要点

- 沿用项目雾白 `#F6F7F3`、墨绿 `#405B50`、灰银 `#DCE0D8`，新增一个只用于封印的陶土色 `#8A5A44`。
- 复用首页的“时间刻度”语言：首屏底部就是一条 2027—2126 的年份轨道，选中的年份会同步到下方的大号年份与信件日期。
- 视觉记忆点：巨大年份、带横线的信纸、旋转的蜡封、顶部压印“已封存”。
- 交互：拖动年份、快捷年份、收信人选择、实时预览、草稿保存在浏览器、封存动画、新的信会插到“已经寄出的信”顶部。
- 无后端、无账户；草稿只存在当前浏览器。页面里写清了这一点，不假装已经发布。
